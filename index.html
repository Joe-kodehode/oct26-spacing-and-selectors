Spacing & Selectors

We can use classes to target multiple elements - allowing us to style them all together.

Specificity determines which targeting takes priority.

A class has more specificity than a general selector and will always take priority over it.

ID has more specificity than class. Inline CSS > ID > Class > general selector

We can use !important to place a property/value to the top of the specificity. If multiple selectors have !important, regular rules apply

Between two block level elements, margins will collapse into eachother and combine. These sections have 50px margin on top and bottom, we only end up with 50px, not 100px between the sections.
