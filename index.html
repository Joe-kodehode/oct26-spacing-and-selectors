Classes, IDs & Spacing

We can use classes to target multiple elements, allowing us to style several elements in the same way.

When multiple CSS rules target the same element, specificity determines which rule takes priority.

A class selector has higher specificity than a general element selector, so the class rule takes priority when both target the same property.

An ID selector has higher specificity than a class selector. In general, specificity follows this order: inline styles > IDs > classes > element selectors.

We can use !important to give a declaration very high priority. However, it should be used sparingly.

If multiple declarations use !important, the normal CSS rules for specificity and the cascade still determine which declaration wins.

When the vertical margins of two block-level elements meet, the margins can collapse into a single margin. For example, if one section has 50px of bottom margin and the next has 50px of top margin, the space between them will usually be 50px rather than 100px.
